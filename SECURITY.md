# Security

Please report a vulnerability privately, through this repository's **Security
→ Report a vulnerability** (GitHub private vulnerability reporting), rather
than in an issue. You will get an answer within a week.

What is in scope: the bindings in this repository, how they download and
verify the engine (`tool/Engine`, `scripts/pin-engine.sh`), and the packages
that carry it. A problem in the engine itself is welcome here too, and is
passed on to where it is fixed.

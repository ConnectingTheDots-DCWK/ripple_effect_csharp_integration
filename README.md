# Ripple Effect for C#

The C# bindings of the [Ripple Effect](https://ripplefx.app) engine: play a
campaign written in the Ripple Effect editor from a game, an app or an engine
of your own, with the same story, the same dice and the same soundscapes the
editor plays. Published to nuget.org as `RippleFx.Engine`, with the engine in
`RippleFx.Engine.Native`.

The bindings are MIT; the engine is under the
[Ripple Effect Runtime Licence](https://ripplefx.app/go/runtime-licence). See
[`LICENSE`](LICENSE).
